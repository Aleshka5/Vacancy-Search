# US3.3: Agent Thinking Process

## Status
**Proposed**

## Story
**As a** user, I want to see the agent's "thinking" process, so that I understand what it's doing.

## Acceptance Criteria

- [ ] **AC1:** Streaming SSE events show agent progress
- [ ] **AC2:** Status updates show each step (parsing, selecting, generating)
- [ ] **AC3:** Token usage is shown in real-time
- [ ] **AC4:** Steps are displayed in chronological order in the UI

## Technical Details

### SSE Events
```
event: step_started
data: {"step": "parsing_vacancy", "timestamp": 1690000000}

event: status
data: {"message": "Анализирую требования к стеку...", "tokens_used": 150}

event: assistant_delta
data: {"content": "Для этой вакансии мне не хватает информации о вашем опыте с "}

event: artifact_created
data: {"artifact_id": "uuid", "type": "resume_pdf", "url": "/api/v1/artifacts/uuid/download"}

event: done
data: {"message_id": "uuid"}
```

### Backend
- `POST /api/v1/chats/{id}/stream` — SSE endpoint
- Uses `EventSourceResponse` from FastAPI
- Streams events as LangGraph agent progresses

### Agent Steps
| Step | Event | Description |
|------|-------|-------------|
| 1 | `step_started` | Parsing vacancy |
| 2 | `status` | Analyzing tech stack |
| 3 | `assistant_delta` | Streaming text |
| 4 | `status` | Selecting context |
| 5 | `status` | Generating TeX |
| 6 | `status` | Compiling PDF |
| 7 | `artifact_created` | PDF ready |
| 8 | `done` | Complete |

### Correlation ID
- UUID generated by FastAPI Middleware
- Propagated through all layers including LangGraph and Podman sandbox
- Used for tracing in Loki
